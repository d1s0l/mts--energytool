# Передача RAG в main

Скопировать содержимое `for_main/rag/` в корневую папку `rag/` ветки `main` с заменой только совпадающих файлов. Не переносить всю ветку `feature/rag-search` и не удалять другие файлы `main/rag/`.

В пакете четыре файла: `rag_search.py`, `tests/test_rag_search.py`, `.env.example`, `README.md`. Версия `rag_search.py` для переноса сохраняет логику поиска, таблиц и `guardrails` из текущего `main`, добавляет диагностику ошибок, метрики этапов, локальный режим по умолчанию и 4 результата по умолчанию.

После переноса запустить тесты: `PYTHONPATH=rag python3 -m unittest discover -s rag/tests -p "test_*.py"`. Затем выполнить интеграционный прогон приложения. Пакет не содержит базу знаний; её путь или архив настраивается отдельно. Полный merge ветки делать нельзя: в `main` есть другие изменения.
